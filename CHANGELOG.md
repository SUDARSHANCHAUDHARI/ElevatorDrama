# Changelog

All notable changes to ElevatorDrama are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-19

### Added

- Interactive cartoon elevator with animated doors and floor progression.
- Ten randomized dramatic trip events followed by a guaranteed arrival.
- Explicit elevator state machine with abortable reset behavior.
- Generated Web Audio sound effects, sound toggle, and volume control.
- Keyboard floor selection, live status announcements, visible focus states, and reduced-motion support.
- Responsive layout, inline SVG scenes, favicon, and installable-site manifest.
- Dependency-free state, contract, security-header, and asset-reference tests.
- Static deployment guidance and security-header configurations for Vercel and Netlify.

# Security Policy

## Supported versions

The latest version on the default branch receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private security advisory feature for this repository. If that is unavailable, email `sudarshantechlabs@gmail.com` with the repository name, affected files or behavior, reproduction steps, and potential impact.

Do not include credentials, personal data, or destructive proof-of-concept payloads. Acknowledgement is normally provided within seven days. Confirmed issues will be fixed and disclosed after a safe release is available.

## Security posture

ElevatorDrama is a client-only static site. It has no authentication, backend, database, analytics, remote API calls, cookies, local storage, or runtime dependencies. Generated sound uses the browser's Web Audio API and does not load external media.
